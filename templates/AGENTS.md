# Cloudflare 项目启动规则

保留项目已有规则，将本节合并进去；它不替代用户授权，也不规定唯一架构。

- 当需求涉及 Cloudflare 选型、公共动态接口、高频轮询或推送时，运行 `$cloudflare-cost-review`；未安装时读取仓库中的同名 `SKILL.md`。
- 写代码前明确数据新鲜度、预计访问量、并发在线时长、日/月预算。信息缺失时记录保守假设，继续不依赖这些答案的工作。
- 交付每条请求的执行与计费路径。区分浏览器缓存、CDN、Workers Cache、Cache API、DO、数据库及对象存储；用量单位不能互换。
- 同时提供正常、增长、异常请求的成本模型；共享月额度只分配一次，短窗口估算不要冒充月账单。
- 公共共享读优先评估能避开动态计费入口的分发方式。个性化/权限数据不得放入共享公开缓存。写入持久化、幂等后才返回成功。
- 公开接口防护需覆盖域名、默认地址、预览、dev 和源站绕过入口。需要减调用费时，验证拦截发生在收费入口之前。
- CPU 限制不等于月费封顶；告警不等于自动停服。说明降级行为、权限、检测/执行延迟和失效情况下的剩余暴露。
- 必须做好账号级全局账单报警，覆盖跨产品用量费用并另核对固定费用。验收分级阈值、实际送达、主动巡检、负责人及处置流程；单次调用限制、单产品提醒或同账期一封邮件不能替代持续费用监控。核对平台的提醒频次和延迟，不声称预算告警是硬封顶。
- 上线验证使用经授权的小样本，核对 Worker 调用、存储操作和缓存响应；不为了证明防护而发起真实大流量。
- 每次交付区分本地完成、已提交、已部署、线上验证、计费验证。没有证据的项目写“待验证”，不得写“已安全”。
- 涉及 API 配置时先给用户实际配置页 URL。密钥通过秘密管理或安全输入写入，不进入源码、命令参数、日志或文档。
